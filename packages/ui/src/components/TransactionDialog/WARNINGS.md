# Signing screen warnings

What each warning on the transaction screen does, and who asked for it. The rule for each one is what was requested. To change a warning, change its row here in the same PR and quote the new request.

| Warning                   | Shown when                                                                                                                                                             | Rule                                                                                                                                                           | Requested by                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unreadable bridge call    | A call to a pinned Across or Relay contract cannot be decoded, or decodes but breaks a rule. Not shown for bytes after the arguments, or for a call that moves nothing | A small warning icon, with the explanation on tap. No line of text. The explanation says what the screen cannot confirm, e.g. where a deposit sends the funds. | Leo, 2026-10-27: "we need to remove the warning line, if it fails to decode". Leo, 2026-10-28: "It shouldn't show all these big messages. maybe a warning logo, but not this big". Leo, 2026-11-02: "What do you think about allowing any trailing bytes?" and "Calls that can only revert [...] already show \"Transaction will fail\", so the red icon might be a second warning for the same thing" ([#622](https://github.com/JustaLab-co/jaw-mono/pull/622)) |
| Unverified bridge token   | A bridge transfer moves a token that is not in the pinned table                                                                                                        | Keep the warning message. No "unverified" tag, since it hid the token name.                                                                                    | Ghadi, 2026-10-30: "remove the unverified tag as it also hides the token name, and keep only the warning msg" ([#610](https://github.com/JustaLab-co/jaw-mono/pull/610))                                                                                                                                                                                                                                                                                          |
| Unknown token amount      | A token's `symbol()` or `decimals()` cannot be read                                                                                                                    | Show the token and its amount with its real decimals. Raw base units only when the read fails, with a note saying so.                                          | Leo, 2026-10-29: "are we reading the token metadata as in the decimals from its address, because the decimal calculation is failing" ([#609](https://github.com/JustaLab-co/jaw-mono/pull/609))                                                                                                                                                                                                                                                                   |
| Unknown destination chain | A bridge deposit with no message goes to a chain the pinned table lacks                                                                                                | A notice instead of the red icon. The recipient shows in full, never as "This account", since the address may not be this account on that chain.               | Leo, 2026-11-02: "When the destination chain isn't in the table but the message is empty, we still know the recipient and the amount. Maybe that could be a notice instead of red?" ([#622](https://github.com/JustaLab-co/jaw-mono/pull/622))                                                                                                                                                                                                                    |
| Unconfirmed swap output   | A same-chain Relay swap through the approval proxy: the call says what leaves the account but not what the swap pays out                                               | A notice that the screen cannot confirm what you get. The simulated amount still shows under You get, marked "Simulated, not guaranteed."                      | Mariano, 2026-11-04: "the owner's signing screen should read a same-chain Relay swap as a swap and never show less than the generic review screen"                                                                                                                                                                                                                                                                                                                |
